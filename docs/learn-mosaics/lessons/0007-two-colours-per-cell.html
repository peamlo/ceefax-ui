Ink and band

A glyph is drawn in one colour, the CSS color, and sits on one background. So every cell has two colours: the ink paints its lit blocks, the band everything else, including a separated mosaic's gaps. Here is one cell of the Banner's title, big:

🬎

The two attributes, as mosaic.css reads them:

:where(.cf-mosaic[data-variant], .cf-mosaic [data-variant]) {
  color: var(--_variant, currentcolor);
}
:where(.cf-mosaic[data-band], .cf-mosaic [data-band]) {
  background: var(--_band, transparent);
  color: var(--_band-ink, var(--_variant, currentcolor));
}

The colour names are the six teletext colours: red, green, yellow, blue, cyan, magenta. The variant seam in base.css turns each name into --_variant, --_band and --_band-ink, the same for every component, not just mosaics.

Colour runs

Both attributes also work on a <span> inside the mosaic, so one mosaic can hold several colours, one run of cells each. Letters typed into a mosaic fall back to Bedstead text. This is the temperature key from the story In the Screen frame: 

<span class="cf-mosaic" role="img" aria-label="Temperature key: red hot, yellow mild, cyan cold">
<span data-variant="red">████</span> HOT
<span data-variant="yellow">████</span> MILD
<span data-variant="cyan">████</span> COLD</span>
████ HOT ████ MILD ████ COLD

A span can change colour at any cell, but it can't give one cell a third colour: a glyph still has one ink and one background. A picture that needs three colours in a cell has to be redrawn so each colour gets whole cells, as teletext artists did (ADR-0021). On a real set it was stricter still: colour changed through control characters that each took up a cell of their own (Teletext Wiki).

Themes and forced colours

The colours are tokens, so a theme moves them. Under the Accessible theme (data-theme="accessible") the band colours lighten and every banded ink turns black, so shapes keep their contrast (ADR-0017). The Banner's title, default and Accessible:

🬏 🬞 🬭🬭🬭 🬞🬭🬏 🬲🬹🬷 █🬋🬃 █🬋█ 🬂 🬂 🬂🬂🬂 🬂 🬂 🬏 🬞 🬭🬭🬭 🬞🬭🬏 🬲🬹🬷 █🬋🬃 █🬋█ 🬂 🬂 🬂🬂🬂 🬂 🬂

Under Windows' forced colours, the browser would repaint all text in one system colour and drop backgrounds, and a picture would lose its shape. So mosaic.css opts mosaics out (forced-color-adjust: none) and keeps their colours on the teletext black.

Last piece: why the font blocks

You've met the mosaic font face's unicode-range (lessons 2 and 3). Its other line is font-display: block. While Bedstead downloads, text in the fallback font is fine, but mosaics would show empty boxes, because fallback fonts may lack the glyphs. So the mosaic face blocks: cells stay blank until the font arrives, while text keeps swap. Browsers stop blocking after about three seconds, so the Mosaic docs suggest preloading the font on pages with mosaics. That's in src/tokens/typography.css and the Storybook Mosaic page.
