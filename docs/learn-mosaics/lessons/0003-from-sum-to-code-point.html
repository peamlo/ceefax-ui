The sextants are in sum order

Unicode 13.0 added the mosaics as “block sextants”, starting at U+1FB00, and seats them in sum order: sum 1 in U+1FB00 (offset 0), sum 2 in U+1FB01 (offset 1), and so on. The offset is one less than the sum, because sum 1 takes the first seat. So the code point is U+1FB00 + (sum − 1). Almost: there are 63 sums but only 60 seats, U+1FB00 to U+1FB3B. Look at 21:

Sum 21 is the whole left column, and Unicode already had that shape: ▌ LEFT HALF BLOCK, in Block Elements since Unicode 1.1. So 21 gets no seat in the row, and 22 takes the seat 21 would have had. From there on, every offset is one lower. The same happens at 42 (▐ RIGHT HALF BLOCK, U+2590) and 63 (█ FULL BLOCK, U+2588).

Three ranges

So the row splits into three ranges. Find the sum's range, subtract, then write the offset in hex:

21, 42, 63not in the row: ▌ ▐ █
  1. sum 48 is in 43–62
  2. 48 − 3 = 45
  3. 45 = 2 × 16 + 13 = 0x2D
  4. U+1FB2D

Backwards, the offsets column tells you the range: U+1FB14 is offset 0x14 = 20, which is in 20–39, so the sum is 20 + 2 = 22.

The formula, as the code writes it

From stories/_mosaic.js:

if (bits === 21) return '▌';
if (bits === 42) return '▐';
if (bits === 63) return '█';
return String.fromCodePoint(0x1fb00 + bits - 1 - (bits > 21) - (bits > 42));

(bits > 21) is a boolean, and JavaScript counts it as 1 or 0 in arithmetic. So the code subtracts 1, plus 1 more once the sum is past 21, plus 1 more once it is past 42: the three ranges in one line.

Separated: no gaps, but a different start

Unicode 16.0 added the separated mosaics at U+1CE51. There were no older separated characters to reuse, so all 63 are in sum order with no gaps: the offset is always sum − 1, with no ranges.

The row starts at …51, not …00, so the last two digits are not the offset. You have to add it to 0x51. The Banner's dotted rule is sum 12, the middle row:

  1. offset: 12 − 1 = 11
  2. 0x51 = 5 × 16 + 1 = 81, and 81 + 11 = 92
  3. 92 = 5 × 16 + 12 = 0x5C
  4. U+1CE5C, 𜹜 (not U+1CE0B, which is 11 seats on from U+1CE00)

In decimal terms: if a row starts at seat 151, the 12th seat is 162, not 111.

Where this shows up in the repo

The mosaic font face in src/tokens/typography.css covers only the characters a mosaic uses: 

unicode-range: U+2580-259F, U+1FB00-1FB3B, U+1CE51-1CE8F, U+EE00-EE7F;

You can now read three of those four ranges. U+EE00–EE7F is Bedstead's private-use copy, for a later lesson.
