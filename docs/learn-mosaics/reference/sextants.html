Sum = total of lit blocks, 0–63. 0 is a space. Mostly lit? Sum = 63 − dark blocks.

Sum → code point

  • Contiguous: U+1FB00 + offset, by range: sums 1–20 → sum − 1 · 22–41 → sum − 2 · 43–62 → sum − 3. Sums 21, 42, 63 are older block elements: ▌ U+258C, ▐ U+2590, █ U+2588.
  • Separated: U+1CE51 + (sum − 1), always − 1, no ranges (Unicode 16.0). Add in decimal: 81 + offset, back to hex. Sum 12 → 81 + 11 = 92 = 0x5C → U+1CE5C. Mark the mosaic data-mosaic="separated".
  • In code: cell(sum, separated) in stories/_mosaic.js.
  • Reverse (contiguous): offsets 0–19 → offset + 1 · 20–39 → offset + 2 · 40–59 → offset + 3.
  • Unicode versions: ▌ ▐ █ 1.1 (Block Elements, U+2580–259F) · sextants 13.0 · separated 16.0. Hence the font's unicode-range: U+2580-259F, U+1FB00-1FB3B, U+1CE51-1CE8F, U+EE00-EE7F.

Hex ↔ decimal

  • Digits: A 10 · B 11 · C 12 · D 13 · E 14 · F 15. Places: 1, 16, 256, 4096.
  • Hex → dec: digit × place, add. 0x2D = 2 × 16 + 13 = 45.
  • Dec → hex: ÷ 16, remainders read last to first. 45 ÷ 16 = 2 r 13 → 0x2D.
  • Console: (45).toString(16) → '2d' · parseInt('2D', 16) → 45.
  • Contiguous offset = last two hex digits (the row starts at …00): U+1FB13 → 0x13 = 19. Separated starts at …51: add, 0x51 + offset.

That's teletext's own byte order: a mosaic is 0x20–0x3F or 0x60–0x7F on air, the 32 block moves it up to the 0x60s, and contiguous = U+EE00 + byte. Write the standard code points: private-use ones mean nothing outside this font.

Why cells tile

  • Every Bedstead cell is 0.6em × 1em; mosaic glyphs are drawn to its edges, letters aren't.
  • white-space: pre: newline = new row, space = empty cell (without: one line, spaces collapse).
  • line-height: 1: row = one cell tall (without: gaps; .cf-page is 1.5).
  • letter-spacing: 0: cells touch (without: inherited 0.08em from buttons, links, fastext).
  • display: inline-block: one box beside text (without: text shears the rows).

Typing a code point

  • HTML: &#x1FB39; · JavaScript: '\u{1FB39}' or String.fromCodePoint(0x1fb39).
  • One-cell fix: work out the sum, write the code point. New art: generate it from pixel art (stories/_mosaic.js); a live editor of the project's own is planned (the zxnet editor is the reference).

Separated

  • Same sum, separated code point: U+1CE51 + (sum − 1). ▌ ▐ █ → U+1CE65 · U+1CE7A · U+1CE8F.
  • Bedstead: each block loses a strip on its left (1/6 width) and bottom (~1/10 height); the gaps show the background or band.
  • data-mosaic="separated" is a label only (no CSS reads it); keep it in step with the characters (assertSeparated).

Colour

  • Two colours per cell: ink (lit blocks, CSS color) and band (background, incl. separated gaps).
  • data-variant = ink · data-band = band; band alone → readable ink (black, white on blue); on the mosaic or a span inside it (a run).
  • Accessible theme: bands lighten, banded ink → black. Forced colours: mosaics opt out, keep colours on --cf-bg.
  • Three colours in a cell: impossible, redraw on whole cells. Mosaic font face: font-display: block, blank not tofu while loading.

Unicode names

Unicode names a sextant by lit positions 1–6 (left to right, top to bottom), not values: position n has value 2n−1. BLOCK SEXTANT-35 = blocks 4 + 16 = sum 20 = U+1FB13. Look one up: curl -s https://www.unicode.org/Public/16.0.0/ucd/UnicodeData.txt | grep ^1FB13.
