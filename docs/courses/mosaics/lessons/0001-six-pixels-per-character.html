The trick: a character is a tiny picture

Each of those characters is a cell, split into 2 × 3 blocks. Unicode gives every on/off pattern of six blocks its own character (“block sextants”), and the Bedstead font draws each one as exactly that pattern, filling the whole cell. So one character carries six pixels, and characters side by side join into a picture.

The logo is three lines of nine characters: 27 cells, 162 blocks. In the story's source the gaps between lines are newlines (\n); your copy shows them as spaces, but white-space: pre in mosaic.css keeps them as rows. Here is the same text with every cell pulled apart:

Every block has a value

A cell's sum is the total of its lit blocks. Six blocks, each on or off, gives 64 sums, 0 to 63:

leftright
top12
middle48
bottom1632

The number under each cell above is its sum. The logo's second cell, 🬎, is 1 + 2 + 4 + 8 = 15: top and middle rows lit, bottom row dark, which is the top of the C's hollow. The sum is what cell() in stories/_mosaic.js turns into a character; how it picks the code point is the next lesson.
