Mosaics · Lesson 4

Why the cells tile

The CF logo is 27 separate characters, yet it reads as one picture. That takes two things: a font whose mosaic glyphs fill their cell, and five lines of CSS that put every cell edge to edge.

1. The glyph fills its cell

Every Bedstead character sits in the same box: 0.6em wide and 1em tall. At a font size of 100px that is 60 × 100 pixels, whatever the character (it's a monospaced font). A letter is drawn inside its box with space around it. A mosaic glyph is drawn to the edges of the box, so its blocks reach the box next door:

AB█🬎🬝

Pulled apart a little, with each character's box dashed: A and B leave a margin; █ fills its box completely, and 🬎 and 🬝 reach every edge where they have a lit block. So any two mosaic cells side by side, or one above the other, meet with no seam. That's the font's half of the job.

2. Five lines of CSS put the boxes edge to edge

The font only works if nothing pushes the boxes apart. That is all mosaic.css does: 

:where(.cf-mosaic) {
  display: inline-block;
  font-family: 'Bedstead Mosaic', 'Bedstead Cell', 'Bedstead', monospace;
  line-height: 1;
  letter-spacing: 0;
  white-space: pre;
}
declarationits jobwithout it
font-familyBedstead's glyphs, which fill the cellanother font's shapes, or empty boxes
white-space: prenewlines start rows; every space is an empty cellthe rows run into one line, and runs of spaces shrink to one
line-height: 1each row is exactly 1em: one cell talla gap between rows (.cf-page sets 1.5)
letter-spacing: 0no gap between cellsa gap after every cell (buttons, links and fastext keys set 0.08em)
display: inline-blockthe picture is one box that text flows aroundtext before it pushes only the top row right, so the picture shears

Line height and letter spacing are inherited: a mosaic takes them from whatever it sits in. That's why the component resets them rather than trusting the page. On MDN: white-space, line-height, letter-spacing, display.

Break it yourself

Untick one declaration at a time and watch what happens to the logo and the text around it:

The font-family switch may change almost nothing: if your system has a fallback font with mosaic glyphs, the browser uses it. Many systems don't, and show empty boxes instead, and a fallback's cells needn't be 0.6em wide. The library can't count on luck, so it names Bedstead, and the Mosaic stories check that every cell is exactly one Bedstead advance wide (assertCells in Mosaic.stories.js).
