TELETEXT FIDELITY
Review · 27 October 2026

A dated snapshot of a design session that compared ceefax-ui with the real thing, using the zxnet teletext site and wiki as ground truth. It records what is missing between today's look and an authentic teletext page, and what was decided for each gap. Like every review here, it does not stay current: the GitHub issues it spawns are canonical.

The rule behind every decision: styled by default, strict teletext only inside the Screen frame. Outside the frame, web standards win (readable body text, fluid layout). Inside it, authenticity wins, unless the Accessible theme also applies.

P101With thanks

This review would not exist without Teletext Stuff at zxnet.co.uk by ZXGuesser and the contributors to the Teletext Wiki. Their viewer, editor, gallery and spec pages showed how teletext actually looked and behaved. Thanks also to Ben Harris for Bedstead, the public-domain SAA5050 font this review proposes adopting.

Summaries and archive links for every page used: docs/reference/zxnet-teletext.md.

P105How to use this

Each decision becomes a GitHub issue that carries its own ADR, glossary and Storybook updates. The first Screen frame ticket writes the shared ADR ("Screen frame is the authentic mode"); later tickets reference or amend it. Glossary terms added in this session: Cell, Subpage, Mosaic, Header row, Title band.
