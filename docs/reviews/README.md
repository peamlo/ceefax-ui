# Reviews

Dated, point-in-time reviews of the repo. Unlike ADRs (one decision each, kept current) and
`CONTEXT.md` (the living glossary), a review is a **snapshot**: it records what was true and
what was proposed on the day it was written, and is never edited to stay current.

Each review's actionable items are filed as GitHub issues; **the issues are canonical**, the
review is the context they came from. Open the `.html` files in a browser (they load Tailwind
and Mermaid from a CDN).

## Index

- [2026-10-25 — CI checks](./2026-10-25-ci-checks.html): security, static checks, bundling,
  token exposure, accessibility, dead code. All checks are free for a public repo; ranked for a
  solo maintainer.
